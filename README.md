# 🍻 Pub Finder

A React Native app for discovering pubs in your local area — or anywhere you choose.

**Pub Finder** helps you quickly find the right pub for the occasion, whether you're looking for somewhere **dog-friendly**, **child-friendly**, or a pub that **shows live football**.

Search an area, browse pubs, apply filters, and save your favourites for later.

---

## ✨ Features

* 📍 **Search your local area**
  Discover pubs near your current location.

* 🔎 **Search any area**
  Choose a different town, city, or location and explore pubs there.

* 🐕 **Dog-friendly filter**
  Find pubs that welcome dogs.

* 👨‍👩‍👧 **Child-friendly filter**
  Find pubs suitable for families.

* ⚽ **Live sport filter**
  Find pubs that show live football and other sport.

* ❤️ **Favourites**
  Save pubs you like for quick access later.

* 🎛️ **Multiple filters**
  Combine filters to narrow down your search and find pubs that match what you're looking for.

* 📱 **Native mobile experience**
  Built specifically for iOS using React Native.

---

## 📱 How It Works

### 1. Choose an area

Use your current location to discover pubs nearby, or search for a different area.

### 2. Browse pubs

View a list of pubs matching your selected location.

### 3. Apply filters

Refine your results based on what matters to you:

* 🐕 Dog friendly
* 👨‍👩‍👧 Child friendly
* ⚽ Shows football

Filters can be combined to create a more targeted search.

### 4. Save favourites

Found somewhere you want to remember?

Add it to your **Favourites** and easily find it again later.

## 🏗️ Architecture

The application is built with React Native and TypeScript, with an emphasis on:

* Reusable components
* Strong TypeScript typing
* Separation of UI and application logic
* Maintainable feature-based development
* Mobile-first UX
* Scalable filtering and search functionality

The app is designed to make discovering local pubs fast and straightforward, while keeping the underlying codebase maintainable as new functionality is added.

The goal of Pub Finder is simple:
